QC Request Screening

Requester Items – QC Screening & Comments

When the Requester submits an inspection request to QC, all requested Tag + Activity items are automatically populated in this QC Screening table under Make / Process RFI. Activity No. and Activity Description are shown for each item. QC can review each item and add comments where required. Any ready item with no QC comment is automatically cleared to proceed to formal RFI. Items with QC comments or failed readiness/prerequisite validation are returned/held and isolated from formal RFI generation.
